# sfx-library – ספריית אפקטי סאונד לעריכת וידאו

כלי שורת פקודה לחיפוש, בחירה ומיקס של אפקטי סאונד מתוך ספרייה מקומית.

- `sfx.py`: הפקודות find, pick, mix, check
- `catalog.jsonl`: הקטלוג של כל האפקטים (שם, תגיות, משך, מקור)
- `page.html`: עמוד שמאפשר לעיין בקטלוג

קבצי השמע לא נכללים בריפו בגלל הגודל והרישיונות. המקורות שלהם הם Kenney ו-Mixkit (CC0 או רישיון חינמי) ו-Sonniss GDC bundle. כל אחד מהם מורידים לתיקייה בשם המקור (`kenney/`, `mixkit/`, `sonniss/`).
